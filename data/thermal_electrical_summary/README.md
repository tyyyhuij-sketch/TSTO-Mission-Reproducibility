# Thermal–electrical reported-results summary

This directory provides a compact, machine-readable summary of selected
thermal–electrical numerical values explicitly reported in the manuscript.

The purpose of this directory is reviewer inspection and documentation only.
It is intentionally limited to reported summary values and is not a complete
raw dataset.

Specifically, these files do **not** provide:

- an executable regenerative-cooling solver;
- an executable thermodynamic-cycle solver;
- a real-fluid-property implementation;
- a chronological energy-storage solver;
- the complete case-wise data underlying every thermal–electrical figure.

The executable reproducibility workflow of this repository remains focused on
the electromagnetic-launch and mission-level vehicle-mass calculations.

## File

`reported_results_summary.csv`

The table records selected values associated with Table 4 and Figs. 6–8,
including mode-resolved electric-pump demand, regenerative-cooling requirement,
finite-cold-source waste-heat recovery, specific electricity generation, and
mission-level battery-storage benefit.

All values in this directory are summary values already reported in the
manuscript. No interpolated or reconstructed case-wise scientific states are
introduced here.

No external proprietary software is required to inspect these files.
